# Local SEO Checklist — Lee Pharmacy

Practical, low/no-cost local SEO checklist for an independent retail pharmacy website (Shopify).

## 1. Google Business Profile (GBP)
- [ ] Claim/verify listing at business.google.com
- [ ] Category: primary "Pharmacy" (add secondary categories if relevant, e.g. "Vitamin & Supplements Store")
- [ ] Business name matches storefront signage exactly (no keyword-stuffed names)
- [ ] Full, accurate address (matches website + all directories)
- [ ] Phone number local format, matches website
- [ ] Accurate opening hours, incl. public holiday hours
- [ ] Add 10+ photos: storefront, interior, staff, products
- [ ] Write business description (750 char max) with natural local + service keywords
- [ ] Add services/products list (e.g. vaccinations, medication compounding, home delivery)
- [ ] Enable messaging / Q&A monitoring
- [ ] Post updates regularly (weekly/fortnightly) — promotions, new stock, health tips

## 2. NAP Consistency (Name, Address, Phone)
- [ ] Website footer/contact page
- [ ] Google Business Profile
- [ ] Facebook / Instagram bio
- [ ] Any online directories (Yellow Pages, TrueLocal, White Pages, Yelp AU)
- [ ] Shopify store settings (Shopify admin > Settings > General)

## 3. On-Site Local SEO
- [ ] Dedicated "Contact / Find Us" page with embedded Google Map
- [ ] Suburb/region name naturally included in: homepage title tag, meta description, H1
- [ ] LocalBusiness (or Pharmacy) schema markup added via JSON-LD
- [ ] Store hours listed on-site, matching GBP
- [ ] Mobile-friendly, fast-loading (test with PageSpeed Insights)
- [ ] Local content: blog posts on local health topics, community involvement, seasonal flu/vax campaigns

## 4. Reviews
- [ ] Set up a simple process to ask happy customers for a Google review (in-store sign, receipt QR code, follow-up SMS/email)
- [ ] Respond to every review (good and bad) within a few days
- [ ] Never buy or fake reviews

## 5. Local Citations / Directories (free)
- [ ] TrueLocal
- [ ] Yellow Pages AU
- [ ] Australian Government / health directories (e.g. Healthdirect Service Finder, if eligible)
- [ ] Local council business directory (if available)
- [ ] Bing Places for Business

## 6. Local Link Building (low cost)
- [ ] Get listed on local council / chamber of commerce site
- [ ] Sponsor or partner with a local community event/school/sports club (often earns a backlink)
- [ ] Partner with nearby complementary businesses (GPs, allied health) for cross-referral/link

## 7. Tracking
- [ ] Connect Google Search Console + verify property
- [ ] Connect Google Analytics 4
- [ ] Monitor GBP Insights (calls, direction requests, website clicks)
- [ ] Track rankings for "[service] + suburb" terms (free tools: Google Search Console query data)

## Free/low-cost tools
- Google Search Console — indexing, query performance (free)
- Google Business Profile — core local listing (free)
- Google PageSpeed Insights — site speed (free)
- Ubersuggest / Google Keyword Planner — keyword ideas (free tier)
- Schema Markup Validator — schema.org validator (free)
